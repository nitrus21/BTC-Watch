# Téléchargements BTC Watch

Ce dossier contient les documents proposés au téléchargement depuis le Web
Flasher officiel.

- [`manuel-btc-watch-v0.9.9.pdf`](manuel-btc-watch-v0.9.9.pdf) — manuel
  utilisateur illustré de 20 pages pour la release BTC Watch 0.9.9.

Le manuel présente l'installation, la première connexion Wi-Fi, les cinq
écrans tactiles, le panneau d'administration, les sauvegardes, le mode panique
et la remise à zéro d'usine avec le bouton BOOT.
